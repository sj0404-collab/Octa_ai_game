## Остаточные проверки на реальном устройстве

Для полного финального допуска signed Android-версии требуется восстановить **исходный** release keystore и его ignored `keystore.properties`, затем повторить `assembleRelease bundleRelease`, `apksigner verify` и установить APK на Android-устройство. На устройстве следует отдельно проверить физическое касание всех кнопок, возврат из 2D карты к игроку и установку обновления поверх предыдущей подписанной сборки.
