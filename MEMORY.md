# Build memory — Night Shift

The project is now a **corporate nightmare-heist roguelite**, not an abstract reactor escape. Preserve the Prism Relay interaction quality — dark glass viewport, decisive mint player agency, coral threat and concise telemetry — but exchange reactor fiction for dense semi-3D office-nightmare rooms. The player’s power is deliberately nonlethal: temporary stun, short teleport, traps, cover and route knowledge.

The main technical risks are a screen-readable tilted camera, procedural office density without unreachable paths, multi-state enemy pressure and durable local progress. Persistent relics must move from run inventory to the diary after successful extraction; achievements must save immediately and visibly. Do not portray the nightmare as a reason for self-harm; the story is about reclaiming time, memory and agency from exploitative work.
